Four Ways to Do Nothing on a Quantum Chip

Can a quantum chip tell apart four gate sequences that all perform the identity operation? I encoded two-bit symbols in four equal-duration sequences on qubit 55 of IBM Kingston and measured each sequence at four phases of a Ramsey interferometer. An ideal qubit gives the same measurement probabilities for every symbol. On Kingston, a decoder trained on the first job identified all 32 blinded symbols in the second job from their fringe angles alone. Applying the secret mask recovered all 64 plaintext bits.

Code Walkthrough

1. Select the physical qubit
Rank qubits by lowest calibrated √X gate error, breaking ties by longest T₁ and then longest T₂. This selected qubit 55 for both jobs.

q* = argmin_q (ε_√X(q), −T₁(q), −T₂(q)) = 55
T₁ = 338.77 µs, T₂ = 86.02 µs

2. Build four physical versions of the identity
Let S = √X. Apply a virtual Z rotation of aπ/2, four S pulses, and the opposite Z rotation, where a is +1 or −1. Each block is exactly the identity because S⁴ = I. Assign a triple of signs (a, b, c) to each symbol. Repeat the triple four times between an opening S and its inverse S³. In the operator products below, the rightmost gate acts first.

B(a) = Rz(−aπ/2) S⁴ Rz(aπ/2) = I
00 → (+,+,+) 01 → (+,−,+) 10 → (−,+,−) 11 → (−,−,−)
U = S³ [B(c) B(b) B(a)]⁴ S = I

3. Measure the Ramsey fringe
Prepare |0⟩, apply S, insert the selected identity sequence U, apply Rz(φ − π), then apply S and measure. Barriers preserve the individual pulses. All 16 combinations of symbol and phase compiled to 54 S pulses and the same duration of 3.908 µs, including readout. If the gates are ideal, the probability of measuring 0 depends only on φ.

P(0 | φ) = |⟨0| S Rz(φ − π) U S |0⟩|² = (1 + cos φ)/2
φ = (0°, 90°, 180°, 270°) P(0 | φ) = (1, ½, 0, ½)

4. Collect labeled samples, then transmit a masked message
Run eight labeled samples per symbol in the early job. For the late job, split a random 64-bit message into 32 two-bit values mᵢ. Draw an independent, uniformly random two-bit mask rᵢ for each value. Their bitwise XOR selects the gate sequence. Shuffle the measurement settings within each job and keep the late labels, masks, and plaintext in a separate answer key.

sᵢ = mᵢ ⊕ rᵢ
N = 4,096 shots per phase
Total shots = (32 early + 32 late) × 4 phases × 4,096 = 1,048,576

5. Learn the alphabet from the early job
For one sample, let kφ be the number of zeros at phase φ and pφ = kφ/N. Estimate the fringe angle from the differences between opposite phases. Pool early counts by symbol to get four reference angles. The angle decoder picks the closest reference using angular distance around the circle.

X = p₀ − p₁₈₀ Y = p₂₇₀ − p₉₀ θ = atan2(Y, X)
ŝ = argmin_s |wrap(θ − θₛ)|, with θₛ the early reference and wrap taking angles into [−π, π)
A second decoder uses all four probabilities. For symbol s, let K(s,φ) be the pooled zero count at phase φ and nₛ the number of early samples used for that symbol. Estimate each probability with a half-count correction, then choose the symbol with the highest binomial log-likelihood.

q(s,φ) = [K(s,φ) + ½] / [nₛN + 1]
ŝ = argmax_s Σφ [kφ ln q(s,φ) + (N − kφ) ln(1 − q(s,φ))]

6. Freeze the late predictions and open the key
Check early accuracy by holding out one whole four-phase sample at a time. Then fit both decoders to all 32 early samples and save their late predictions before opening the answer key. Score each predicted symbol ŝᵢ and apply its mask to recover the predicted plaintext.

Symbol accuracy = (number of correct late symbols) / 32
m̂ᵢ = ŝᵢ ⊕ rᵢ

7. Measure how much information survives with fewer shots
Keep both decoders fixed. For each smaller budget h, draw h shots without replacement from each archived late phase measurement. Repeat 5,000 times at each budget and score the same 32 symbols. The sampled zero count k′φ follows a hypergeometric distribution with kφ zeros among N recorded shots.

k′φ ∼ Hypergeometric(population N, zeros kφ, draws h)
h = 16, 32, 64, 128, 256, 512, 1,024, 2,048, 4,096

# Calibration-based qubit pick
def best_qubit(backend):
    path = Path(CAL_JSON).expanduser() if CAL_JSON else None
    rows = None
    properties = None
    if path is None:
        properties = backend.properties()
    elif path.suffix.lower() == ".csv":
        with path.open(encoding="utf-8-sig", newline="") as file:
            rows = list(csv.DictReader(file))
    else:
        with path.open(encoding="utf-8-sig") as file:
            data = json.load(file)
        if isinstance(data, list):
            rows = data
        else:
            properties = BackendProperties.from_dict(data)

    candidates = []
    if rows is not None:
        for row in rows:
            row = {key.strip(): value for key, value in row.items()}
            try:
                candidates.append((int(row["Qubit"]), float(row["√x (sx) error"]),
                                   float(row["T1 (us)"]), float(row["T2 (us)"])))
            except (TypeError, ValueError):
                continue  # An uncharacterized qubit can have empty cells.
    else:
        if properties is None or properties.backend_name != backend.name:
            raise ValueError(f"Expected calibration properties for {backend.name}.")
        for q in range(min(len(properties.qubits), backend.num_qubits)):
            if not properties.is_qubit_operational(q):
                continue
            try:
                candidates.append((q, properties.gate_error("sx", [q]),
                                   properties.t1(q) * 1e6, properties.t2(q) * 1e6))
            except BackendPropertyError:
                continue

    eligible = [
        (error, -t1, -t2, q) for q, error, t1, t2 in candidates
        if 0 <= q < backend.num_qubits and 0 <= error <= 1
        and 0 < t1 < math.inf and 0 < t2 < math.inf
        and all(backend.target.instruction_supported(operation_name=gate, qargs=(q,))
                for gate in ("sx", "rz", "measure"))
    ]
    if not eligible:
        raise ValueError("No qubit has usable SX, T1, T2 and readout calibration.")
    error, neg_t1, neg_t2, q = min(eligible)
    return q, {"source": str(path) if path else "live backend properties",
               "sx_error": error, "t1_us": -neg_t1, "t2_us": -neg_t2}


# Identity word and Ramsey interferometer
def sx_pulses(qc, q, number):
    for _ in range(number):
        qc.sx(q)
        qc.barrier(q)  # Preserve every physical drive, including adjacent SXs.


def append_identity_word(qc, q, symbol):
    # SX**4 = I, so each RZ-framed quartet is exactly I for either frame.
    # The outer SX and SX**3 are inverses. They rotate residual drive-angle
    # error about the framed +/-Y axis into a Ramsey-sensitive Z phase.
    sx_pulses(qc, q, 1)
    for _ in range(WORD_REPEATS):
        for sign in WORDS[symbol]:
            frame = sign * math.pi / 2
            qc.rz(frame, q)
            sx_pulses(qc, q, 4)
            qc.rz(-frame, q)
            qc.barrier(q)
    sx_pulses(qc, q, 3)


def ramsey_circuit(symbol, phase_deg):
    probe = QuantumRegister(1, "probe")
    readout = ClassicalRegister(1, "readout")
    qc = QuantumCircuit(probe, readout, name="ramsey")
    q = probe[0]
    sx_pulses(qc, q, 1)  # First Ramsey pi/2 pulse.
    append_identity_word(qc, q, symbol)
    # The pi offset inverts the second splitter at phase zero. For every ideal
    # word P(readout=0) = (1 + cos(phase)) / 2.
    qc.rz(math.radians(phase_deg - 180), q)
    qc.sx(q)
    qc.measure(q, readout[0])
    return qc


def native_sequence(qc, physical):
    sequence = []
    for item in qc.data:
        gate = item.operation
        if gate.name == "barrier":
            continue
        if [qc.find_bit(bit).index for bit in item.qubits] != [physical]:
            raise ValueError("Transpilation moved an operation off the selected qubit.")
        if gate.name == "rz":
            angle = round(float(gate.params[0]) % math.tau, 12)
            if angle:
                sequence.append(("rz", angle))
        else:
            sequence.append((gate.name, None))
    return sequence


def compile_alphabet(backend, physical):
    templates = {}
    durations = set()
    for symbol in range(len(WORDS)):
        for phase in PHASES_DEG:
            raw = ramsey_circuit(symbol, phase)
            isa = transpile(raw, backend=backend, initial_layout=[physical],
                            optimization_level=0)
            if native_sequence(isa, physical) != native_sequence(raw, 0):
                raise ValueError("The compiler changed the native Ramsey pulse sequence.")
            durations.add(isa.estimate_duration(backend.target, unit="dt"))
            templates[symbol, phase] = isa
    if len(durations) != 1:
        raise ValueError(f"Compiled Ramsey durations differ in backend ticks: {durations}")
    return templates, int(durations.pop())


# Acquisition plan and private answer key
def acquisition_plan():
    if min(EARLY_SAMPLES_PER_SYMBOL, LATE_SYMBOLS, WORD_REPEATS, SHOTS) < 1:
        raise ValueError("Sample counts, word repeats and shots must be positive.")
    bits = PLAINTEXT_BITS
    if len(bits) % 2 or set(bits) - {"0", "1"}:
        raise ValueError("PLAINTEXT_BITS must contain complete two-bit symbols.")
    plaintext = ([int(bits[i:i+2], 2) for i in range(0, len(bits), 2)]
                 if bits else [randbits(2) for _ in range(LATE_SYMBOLS)])
    early = list(range(len(WORDS))) * EARLY_SAMPLES_PER_SYMBOL
    rng = SystemRandom()
    rng.shuffle(early)
    key = []
    for sample_id, plain in enumerate(plaintext):
        mask = randbits(2)
        key.append({"sample_id": sample_id, "plaintext": plain, "mask": mask,
                    "symbol": plain ^ mask})

    plans = {}
    for stage, symbols in (("early", early), ("late", [row["symbol"] for row in key])):
        settings = [(sample_id, symbol, phase) for sample_id, symbol in enumerate(symbols)
                    for phase in PHASES_DEG]
        rng.shuffle(settings)  # Submitted order carries no systematic symbol or phase cue.
        plans[stage] = settings
    return plans, key

    temporary = path.with_suffix(".tmp")
    temporary.write_text(json.dumps(data, indent=2) + "\n", encoding="utf-8")
    temporary.replace(path)

def main():
    logging.basicConfig(level=logging.INFO, format="%(asctime)s | %(levelname)s | %(message)s")
    plans, key = acquisition_plan()
    service = QiskitRuntimeService(channel="ibm_quantum_platform" if TOKEN else None,
                                   token=TOKEN or None,
                                   instance=INSTANCE or None)
    backend = service.backend(BACKEND)
    physical, calibration = best_qubit(backend)
    templates, duration_dt = compile_alphabet(backend, physical)
    log.info("Backend %s | qubit %d | all Ramsey circuits %d dt", backend.name,
             physical, duration_dt)
    sampler = SamplerV2(mode=backend, options={
        "dynamical_decoupling": {"enable": False},
        "twirling": {"enable_gates": False, "enable_measure": False},
    })

    run_id = datetime.now(timezone.utc).strftime("%Y%m%dT%H%M%SZ") + "_" + token_hex(4)
    RESULT_DIR.mkdir(parents=True, exist_ok=True)
    prefix = f"Ramsey_Identity_Cipher_{run_id}"
    public_path = RESULT_DIR / f"{prefix}_measurements.json"
    private_path = RESULT_DIR / f"{prefix}_PRIVATE_key.json"
    with open(private_path, "x", encoding="utf-8",
              opener=lambda path, flags: os.open(path, flags, 0o600)) as file:
        json.dump({"run_id": run_id, "late_in_message_order": key}, file, indent=2)

    out = {"experiment": "Ramsey identity cipher", "run_id": run_id, "backend": backend.name,
           "physical_qubit": physical, "calibration": calibration, "shots_per_phase": SHOTS,
           "phases_deg": PHASES_DEG, "word_frame_signs": WORDS, "word_repeats": WORD_REPEATS,
           "compiled_duration_dt": duration_dt, "dt_seconds": backend.dt, "blocks": {}}
    log.info("Measurements -> %s", public_path)
    log.info("Private answer key -> %s", private_path)

    # job.result() and the early checkpoint both finish before the late submission.
    for stage, settings in plans.items():
        records = []
        circuits = []
        for sample_id, symbol, phase in settings:
            record = {"sample_id": sample_id, "phase_deg": phase}
            if stage == "early":
                record["symbol"] = symbol
            records.append(record)
            circuits.append(templates[symbol, phase])
        block = {"records_in_pub_order": records,
                 "submission_requested_utc": datetime.now(timezone.utc).isoformat()}
        out["blocks"][stage] = block
        save_measurements(public_path, out)
        job = sampler.run(circuits, shots=SHOTS)
        block["job_id"] = job.job_id()
        log.info("%s job %s | %d settings x %d shots", stage, job.job_id(), len(records), SHOTS)
        save_measurements(public_path, out)
        result = job.result()
        for record, pub in zip(records, result, strict=True):
            counts = pub.data.readout.get_counts()
            if sum(counts.values()) != SHOTS or counts.keys() - {"0", "1"}:
                raise ValueError(f"Unexpected one-bit counts in {stage} job {job.job_id()}.")
            record["counts"] = counts
        block["result_received_utc"] = datetime.now(timezone.utc).isoformat()
        # Record the device's acquisition windows directly from the Sampler result.
        spans = result.metadata.get("execution", {}).get("execution_spans", ())
        executor = result.metadata.get("executor")
        if executor is not None:
            spans = executor.chunk_timing
        block["qpu_windows"] = [{"start": span.start.isoformat(), "stop": span.stop.isoformat()}
                                for span in spans]
        save_measurements(public_path, out)
    log.info("Acquisition complete. Use %s for blind decoding.", public_path)


if __name__ == "__main__":
    main()

@dataclass
class Block:
    # Rows follow sample ID order. Columns follow PHASES. Values count readout 0.
    counts: np.ndarray
    labels: np.ndarray

    def for_symbol(self, symbol):
        return self.counts[self.labels == symbol]


def load_run(directory):
    stem = f"Ramsey_Identity_Cipher_{RUN_ID}"
    measurements = json.loads((directory / f"{stem}_measurements.json").read_bytes())
    answer_key = json.loads((directory / f"{stem}_PRIVATE_key.json").read_bytes())
    if measurements["run_id"] != RUN_ID or answer_key["run_id"] != RUN_ID:
        raise ValueError("The measurements and answer key must belong to the published run.")
    if tuple(measurements["phases_deg"]) != PHASES:
        raise ValueError(f"Expected analysis phases {PHASES}.")
    shots = measurements["shots_per_phase"]
    key_rows = answer_key["late_in_message_order"]
    truth = {row["sample_id"]: row["symbol"] for row in key_rows}
    if len(truth) != len(key_rows):
        raise ValueError("Duplicate sample ID in the late answer key.")

    blocks = {}
    for stage in ("early", "late"):
        rows = measurements["blocks"][stage]["records_in_pub_order"]
        sample_ids = sorted({row["sample_id"] for row in rows})
        if stage == "late" and set(sample_ids) != set(truth):
            raise ValueError("The late sample IDs do not match the answer key.")
        row_index = {sample_id: index for index, sample_id in enumerate(sample_ids)}
        counts = np.full((len(sample_ids), len(PHASES)), -1, dtype=int)
        labels = np.full(len(sample_ids), -1, dtype=int)
        for row in rows:
            sample_id = row["sample_id"]
            i, j = row_index[sample_id], PHASES.index(row["phase_deg"])
            histogram = row["counts"]
            if counts[i, j] != -1 or set(histogram) - {"0", "1"}:
                raise ValueError(f"Duplicate setting or invalid readout for sample {sample_id}.")
            if sum(histogram.values()) != shots or min(histogram.values()) < 0:
                raise ValueError(f"Invalid shot count for {stage} sample {sample_id}.")
            counts[i, j] = histogram.get("0", 0)
            symbol = row["symbol"] if stage == "early" else truth[sample_id]
            if symbol not in SYMBOLS or labels[i] not in (-1, symbol):
                raise ValueError(f"Inconsistent symbol for {stage} sample {sample_id}.")
            labels[i] = symbol
        if np.any(counts < 0) or set(labels) != set(SYMBOLS):
            raise ValueError(f"Incomplete four-phase alphabet in the {stage} block.")
        blocks[stage] = Block(counts, labels)
    return blocks, shots

# Image 3 - The symbol cloud and its angle–imbalance projection
def plot_symbol_cloud(blocks, shots, output):
    fig = page("The four symbols in three measured coordinates",
               "Each point is one four-phase measurement. The projection shows why similar fringe angles can still carry different symbols.")
    space = fig.add_axes([.045, .255, .455, .525], projection="3d", proj_type="ortho")
    plane = fig.add_axes([.618, .302, .306, .385])
    space.view_init(elev=22, azim=-53)
    space.set_box_aspect([1.65, 1.12, .93], zoom=1.0)
    for stage, marker in [("early", "o"), ("late", "D")]:
        for symbol, color in enumerate(SYMBOL_COLORS):
            probabilities = blocks[stage].for_symbol(symbol) / shots
            p0, p90, p180, p270 = probabilities.T
            angle = np.degrees(fringe_angle(probabilities))
            imbalance = 100 * (p0 + p180 - p90 - p270)
            contrast = 100 * np.hypot(p0 - p180, p270 - p90)
            style = dict(marker=marker, s=26 if stage == "early" else 21,
                         facecolors="none" if stage == "early" else color,
                         edgecolors=color, linewidths=1.05 if stage == "early" else .55, alpha=.9)

    space.set(xlim=(-27, 1), ylim=(-8, 8), zlim=(93, 98))
    space.set_xticks([-25, -15, -5])
    space.set_yticks([-6, 0, 6])
    space.set_zticks([94, 96, 98])
    space.set_xlabel("Fringe angle (°)", labelpad=4, fontsize=10)
    space.set_ylabel("Imbalance (pp)", labelpad=3, fontsize=10)
    space.set_zlabel("Contrast (%)", labelpad=0, fontsize=10)
    space.tick_params(pad=0, labelsize=8.8)
    for axis in (space.xaxis, space.yaxis, space.zaxis):

        axis.pane.set_edgecolor(GRID)

    plane.set_title("Angle and imbalance", loc="left", fontsize=13, pad=12)

              ylabel="Imbalance (percentage points)")

# Image 4 - Accuracy of the fixed early decoders as the late shot budget changes
def plot_shot_budget(blocks, shots, output):
    early, late = blocks["early"], blocks["late"]
    pooled_counts = np.array([early.for_symbol(s).sum(axis=0) for s in SYMBOLS])
    class_shots = np.bincount(early.labels, minlength=4) * shots
    centers = fringe_angle(pooled_counts)
    profile = (pooled_counts + .5) / (class_shots[:, None] + 1)
    log_zero, log_one = np.log(profile.T), np.log1p(-profile.T)
    budgets = np.array([16, 32, 64, 128, 256, 512, 1024, 2048, 4096])
    if shots != budgets[-1]:
        raise ValueError("The published shot-budget figure uses 4,096 shots per phase.")
    rng = np.random.default_rng(55)
    repeats = 5000
    means = np.empty((len(budgets), 2))
    lower = np.empty_like(means)
    upper = np.empty_like(means)
    for i, budget in enumerate(budgets):
        # Draw an unordered subset of each recorded one-bit shot stream.
        zeros = rng.hypergeometric(late.counts, shots - late.counts, budget,
                                   size=(repeats, *late.counts.shape))
        angle = fringe_angle(zeros)
        distances = np.abs((angle[..., None] - centers + np.pi) % (2 * np.pi) - np.pi)
        phase_prediction = distances.argmin(axis=-1)
        profile_prediction = (zeros @ log_zero + (budget - zeros) @ log_one).argmax(axis=-1)
        correct = np.stack([(phase_prediction == late.labels).sum(axis=1),
                            (profile_prediction == late.labels).sum(axis=1)], axis=1)
        means[i] = correct.mean(axis=0)
        lower[i], upper[i] = np.quantile(correct, [.05, .95], axis=0, method="nearest")

    fig = page("How decoding accuracy changes with fewer shots",
               "The same 32 late symbols were reread using random subsets of their archived shots. Both early decoders stayed fixed.")
    ax = fig.add_axes([.095, .295, .607, .445])
    ax.set_xscale("log", base=2)
    handles = []
    for j, (color, title, marker) in enumerate([("#a45520", "Fringe angle", "o"),
                                                 ("#246982", "Four-phase profile", "D")]):
        ax.fill_between(budgets, lower[:, j], upper[:, j], color=color, alpha=.105, lw=0)
        line, = ax.plot(budgets, means[:, j], color=color, marker=marker, markerfacecolor="white",
                        ms=5.5, lw=2.1, label=title, zorder=3)
        handles.append(line)
    ax.scatter([shots] * 2, means[-1], s=56, marker="o", color=INK, zorder=5, clip_on=False)
    ax.axhline(8, color=GRAY, lw=1, ls=(0, (3, 3)))
    ax.text(19, 8.45, "Uniform guessing · 8 of 32 on average", fontsize=9, color=GRAY)
    ax.set(xlim=(13, 5200), ylim=(6.2, 34), xlabel="Shots retained per phase setting",
           ylabel="Late symbols decoded correctly")
    ax.set_xticks(budgets, [f"{x:,}" for x in budgets])
    ax.set_yticks([8, 12, 16, 20, 24, 28, 32])
    ax.tick_params(length=0, labelsize=9.1, pad=5)
    ax.spines[["top", "right"]].set_visible(False)
    ax.grid(axis="y", lw=.65, color=GRID)
    fig.legend(handles=handles, loc="center left", bbox_to_anchor=(.085, .193),
               ncol=2, frameon=False, fontsize=10.4)
    fig.add_artist(Line2D([.742, .742], [.304, .73], lw=1, color=GRID, transform=fig.transFigure))
    phase_mean, profile_mean = means[budgets == 1024][0]
    fig.text(.765, .678, "1,024 shots per phase", fontsize=12.4, weight="bold")
    fig.text(.765, .629, "Average correct out of 32", fontsize=10, color=GRAY)
    fig.text(.765, .568, f"{phase_mean:.1f}   Fringe angle", fontsize=12.4, color="#964813")
    fig.text(.765, .517, f"{profile_mean:.1f}   Four-phase profile", fontsize=12.4, color="#246982")
    fig.text(.765, .405, "4,096 shots per phase", fontsize=12.4, weight="bold")
    full_phase, full_profile = means[-1]
    text = (f"{full_phase:.0f}/{len(late.labels)} for both decoders" if full_phase == full_profile
            else f"{full_phase:.0f} angle · {full_profile:.0f} profile")
    fig.text(.765, .35, text, fontsize=11.6, color=INK)
    fig.text(.765, .306, "Observed in the full run", fontsize=10, color=GRAY)
    footer(fig, "Lines show mean scores. Shading covers the 5th–95th percentiles of 5,000 random "
           "subsets drawn without replacement at each shot count.",
           "Each symbol uses four phase settings. These ranges describe shot sampling within this run. "
           "Drift across hardware runs adds further uncertainty.")
    save(fig, output / "04_Kingston_shot_budget.png", dpi=180)
